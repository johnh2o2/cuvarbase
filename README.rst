cuvarbase
=========

.. image:: https://badge.fury.io/py/cuvarbase.svg
    :target: https://badge.fury.io/py/cuvarbase

``cuvarbase`` is a Python library that uses `PyCUDA
<https://mathema.tician.de/software/pycuda/>`_ to implement several time
series tools used in astronomy on GPUs (BLS, Lomb-Scargle, conditional
entropy, PDM, and more).

The full project README is `README.md
<https://github.com/johnh2o2/cuvarbase/blob/v1.0-fixes/README.md>`_ (the
canonical document; this file is just a pointer). Documentation:
https://johnh2o2.github.io/cuvarbase/
